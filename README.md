# 🫧 Glass

### Glass, New Way to Experience Windows.

Glass is a Windows application inspired by the Dynamic Island concept, bringing a modern, fluid and minimal interface to your desktop.

Designed around the Liquid Glass aesthetic, Glass transforms the way you interact with notifications, media playback and system information.

## ✨ Features

- **Dynamic Island** — a floating interactive interface for Windows.
- **Pill & Notch** — compact and expanded interface states.
- **Music Widget** — access media information and playback controls.
- **Notifications** — display notifications in a modern, integrated interface.
- **Animations** — smooth transitions and fluid interactions.
- **Customization** — personalize the appearance and behavior of Glass.

*Glass is actively evolving. Features and functionality may change between releases.*

## 🖥️ Requirements

- Windows 11
- A 64-bit Windows system

## 📥 Download

You can download the latest available version from the [Releases](https://github.com/dissentt/Glass/releases) page.

1. Open the Releases page.
2. Download the latest available build.
3. Extract the archive if necessary.
4. Run `Glass.exe`.
